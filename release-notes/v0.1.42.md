A new Audio Only page. Drop audio on its own and choose AUDIO ONLY for a page built just for sound, in three sections. QC measures every file against your spec and now lays the results out in a table, with a stereo check that catches dual mono, one-sided and anti-phase files. File Deliverables render to a spec in one click: Normalise, 6 Fr, Clock, and a new Convert to WAV, AIFF, FLAC, ALAC or AAC at 44.1k, 48k or 96k, 16, 24 or 32-bit float. File Processing changes the shape of a file: split a multichannel file into named mono stems, join stems back into stereo, 5.1 or 7.1, fold surround to stereo or anything to mono, fade the ends, or trim head-and-tail silence. New files always land beside the originals. Also: waveforms in the preview player, and every audio file now shows its sample rate and bit depth.
